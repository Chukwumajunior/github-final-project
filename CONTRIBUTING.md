# Contributing Guidelines

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Review the existing project files and documentation.
2. Identify a bug, improvement, or feature to work on.
3. Create a branch for your changes.
4. Make your changes and test them.
5. Commit your changes with a clear commit message.
6. Submit a pull request describing your changes.

## Reporting Bugs

When reporting a bug, please include:
- A clear description of the problem.
- Steps to reproduce the issue.
- The expected behaviour.
- The actual behaviour.

## Suggesting Enhancements

Suggestions for new features and improvements are welcome. Explain the proposed change and how it would benefit the project.

## Code Style

Keep code simple, readable, and consistent with the existing project.

## Testing

Test your changes before submitting them. For the simple interest calculator, verify that the result is calculated correctly using the formula:

`Simple Interest = (Principal × Rate × Time) / 100`

## Pull Requests

- Provide a clear description of your changes.
- Keep changes focused on a specific issue or improvement.
- Ensure that documentation is updated where necessary.
- Be respectful when responding to review feedback.

Thank you for contributing to the project!
